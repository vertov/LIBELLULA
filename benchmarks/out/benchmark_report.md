# Libellula Comparative Benchmark

Generated by `python3 benchmarks/run_benchmarks.py`. All stimulus is synthetic.

Method and scope:
- Error is Euclidean MAE (px) between a prediction and ground truth h scenario cycles after the newest event the tracker had seen (h = 1, 4, 8).
- Baselines are floating-point Python trackers updated on every event. `libellula_core` is the RTL (Icarus Verilog, default parameters, DW=4), which emits a prediction only when the burst gate passes an event, so its prediction count is lower.
- Each Libellula prediction is paired with the newest input event that could have produced it (presented >= the fixed pipeline depth earlier). Libellula horizons > 1 are extrapolated from successive predictions.
- Libellula `latency_mean` is measured in simulation from that event to `pred_valid` (driver clock convention, +1 cycle vs `tb_latency`). Baseline latencies are nominal constants assigned in `baselines.py`, not measurements.
- False-lock: reporting lock while horizon-1 error exceeds 5 px. Compute cost is a per-event operation proxy, Libellula fixed at 1.0.
- Composite score (lower is better) is the weighted sum in `score_candidate()`; it is a convenience ranking, not a figure of merit for hardware.
